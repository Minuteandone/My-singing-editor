How to use Rig Lab

Quickest: Select the full data.zip, filter for monster_cd.json (Fwog) and select it. The editor finds its XML and AVIF atlas in the archive automatically. No 462 MB extraction is needed.

Or choose three individual files such as monster_cd.json, monster_CD_sheet.xml, and monster_CD_sheet.avif. Supported inputs are converted Aniviewer JSON (Rev 2/5/6 compatible where fields exist), TexturePacker XML, and local atlas images. File contents remain in your browser.

The original track plays through the hierarchy. Selecting layers lets you add separate transforms or limits. A two-joint IK chain uses three related layers and is only offered when the source hierarchy supports it. IK is approximate when transforms are nonuniform or a source layer is degenerate.

This editor uses rigid sprites; it does not perform mesh deformation or recover unexported controls. Aniviewer may support further game-specific features that this editor does not yet handle, including complex shaders, meshes, and draw-order changes.
Fan-made local animation tooling. Bring your own legitimately obtained assets. No game art or source animations are bundled in this new editor. Built with reference to the open-source MSM Aniviewer project.
